# AI for Everyday Life

Simple, reusable AI solutions for problems everyone faces, built with Claude.

## About

This repository documents practical ways to use Claude to solve common, everyday problems — the kind most people deal with every week. Each case includes the problem, the solution, and the prompts or skills so anyone can reuse them.

## Cases

| # | Problem | Solution | Status |
|---|---------|----------|--------|
| 1 | Making a difficult decision (job change, buy vs rent, accepting an offer) | Structured decision-making prompts | 🔜 Planned |
| 2 | Organizing household finances | Project + budget dashboard | 🔜 Planned |
| 3 | Understanding complicated documents (leases, bills, terms of service) | Skill that translates documents into plain language | 🔜 Planned |
| 4 | A chaotic week of emails and appointments | Weekly agenda and email summary | 🔜 Planned |
| 5 | Making a purchase decision or planning a trip | Structured comparative research | 🔜 Planned |
| 6 | Meal planning and grocery lists | End-to-end solution combining all features | 🔜 Planned |
